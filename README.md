# FoodHub Admin Overview

FoodHub Admin is the management dashboard for the FoodHub platform.

It allows administrators to manage users, stores, food, dietary and health-related data, and other system resources through a simple dashboard.

## Main Features

- User management
- Store management
- Food and menu management
- Allergen management
- Dietary type management
- Medical condition management
- CRUD operations
- Search and filtering
- Pagination
- Store status management
- Image and media management
- Google Places integration
- Admin authentication and authorization

## Purpose

The purpose of FoodHub Admin is to provide administrators with an easy and secure way to manage the data used by the FoodHub application.
